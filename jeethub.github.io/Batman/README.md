# Batman Interactive Wallpaper

A small, dependency-free interactive web page built with HTML, CSS, and JavaScript. Move the pointer across the scene to reveal the image beneath the dark mask.

## Run

Open `index.html` directly in a modern browser. To serve it locally instead, run this from the project directory:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>.

## Project files

- `index.html` contains the page structure.
- `styles.css` defines the scene and responsive layout.
- `script.js` handles pointer interaction.
- `batman-8510022_1280.png` and `Bruce wayne.jpg` are visual assets used by the page.

There is no build step or package installation. The optional Google Fonts import falls back to local fonts when offline.
